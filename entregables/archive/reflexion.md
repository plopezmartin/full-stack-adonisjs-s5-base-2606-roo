 # Reflexiones tras ejecutar el prompt de descomposición de PRD en user stories.
1. El patrón de Given/When/Then lo respetó, pero no lo formateó en estilo Gherkin/BDD, como lo esperaba.
2. No quise poner el ejemplo de user story para no condicionarle y limitar a la IA, pero quizá así sí que hubiera formateado bien los escenarios de Given/When/Then.
3. No le indique que incluyera happy path y edge cases. Esto se complementa con el poke-a-hole review, pero deberia de haberlo tambien indicado en el prompt inicial.
5. Me sorprendió positivamente que sugería orden de dependencias, las agrupada por épicas, y que añadía una sección de open questions.
6. Definió una user story de spike, desde el punto de vista del product owner con el outcome que se espera.
7. El technical context no se añadio para todas las historias, aunque dijo que lo añadio al final de cada US.
8. Usar IA de poke-hole es super potente.
